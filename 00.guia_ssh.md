# Guía: Conexión SSH sen contrasinal e uso remoto con VS Code

## 1. Introdución

O obxectivo é establecer unha conexión SSH segura e sen contrasinal entre un host e outro equipo remoto (servidor, contedor ou máquina virtual), e poder traballar con el desde VS Code coma se fose local.

---

## 2. Xeración e configuración de claves SSH (válido para calquera host)

### 2.1. Xerar un par de claves SSH

No equipo **host**, executa:

```bash
ssh-keygen -t ed25519 -C "tua_identidade"
```

- Ruta por defecto: `~/.ssh/id_ed25519`
- Sen frase de paso (opcional)
  
Crea:
- **Privada:** `~/.ssh/id_ed25519`
- **Pública:** `~/.ssh/id_ed25519.pub`

---

### 2.2. Copiar a clave pública ao host remoto

Conéctate ao servidor remoto (por contrasinal a primeira vez):

```bash
ssh usuario@ip_ou_nome_do_host
```

No remoto:

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
```

Desde o host, copia a clave pública:

**Linux/macOS:**
```bash
cat ~/.ssh/id_ed25519.pub | ssh usuario@ip_ou_nome_do_host "cat >> ~/.ssh/authorized_keys"
```

**Windows (PowerShell):**
```bash
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh usuario@ip_ou_nome_do_host "cat >> ~/.ssh/authorized_keys"
```

No remoto:

```bash
chmod 600 ~/.ssh/authorized_keys
```

---

### 2.3. Simplificar o acceso con `~/.ssh/config`

No host:

```bash
Host nome_alias
  HostName ip_ou_nome_do_host
  User usuario
  IdentityFile ~/.ssh/id_ed25519
```

Agora podes conectarte cun simple:

```bash
ssh nome_alias
```

---

### 2.4. Verificación de permisos e depuración

Se hai problemas:

```bash
ssh nome_alias -v
```

Verifica permisos:

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

---

## 3. Uso con VS Code (Remote - SSH)

1. Instala a extensión **Remote - SSH**.  
2. `F1` → `Remote-SSH: Connect to Host…`  
3. Escolle o alias configurado.  
4. VS Code instalará o servidor remoto automaticamente.  
5. Abre carpetas remotas ou usa o terminal integrado.

---

## 4. Caso especial: Conexión SSH a máquinas virtuais en VirtualBox (NAT + Port Forwarding)

### 4.1. Configurar o port forwarding

En VirtualBox → Configuración da VM → Rede → Avanzado → Reenvío de portos:

| Nome | Protocolo | IP anfitrión | Porto anfitrión | IP convidado | Porto convidado |
|------|------------|--------------|----------------|--------------|----------------|
| SSH  | TCP        | —            | 3022           | —            | 22             |

Isto permite conectarte dende o host ao porto 3022 e acceder ao SSH da VM (22).

---

### 4.2. Acceso e copia da clave pública

Proba primeiro con contrasinal:

```bash
ssh -p 3022 usuario@localhost
```

Logo copia a clave pública (desde o host):

```bash
scp -P 3022 ~/.ssh/id_ed25519.pub usuario@localhost:~/.ssh/authorized_keys
```

Ou co método alternativo (`cat >>`), igual que antes.

---

### 4.3. Configurar o alias para a VM

```bash
Host nome_vm
  HostName localhost
  Port 3022
  User usuario
  IdentityFile ~/.ssh/id_ed25519
```

Conéctate simplemente con:

```bash
ssh nome_vm
```

---

### 4.4. Uso en VS Code

Conéctate a `nome_vm` desde **Remote - SSH** e abre carpetas dentro da VM (por exemplo `/home/usuario`).

---

## 5. Resumo

| Paso | Acción | Comando principal |
|------|---------|------------------|
| 1 | Xerar clave SSH | `ssh-keygen -t ed25519` |
| 2 | Copiar clave pública | `cat ~/.ssh/id_ed25519.pub | ssh usuario@host ...` |
| 3 | Simplificar acceso | Editar `~/.ssh/config` |
| 4 | Conectarte desde VS Code | `Remote-SSH` |
| 5 | (VirtualBox) Port forwarding | Host 3022 → VM 22 |
