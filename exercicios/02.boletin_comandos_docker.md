# Boletín de ejercicios prácticos de Docker

---

## 1. Verificación inicial
**Objetivo:** Comprobar que Docker está correctamente instalado.  
**Instrucciones:**
1. Muestra la versión del motor Docker y del cliente.  
2. Lista información general del sistema Docker.  
3. Ejecuta el contenedor de prueba oficial para comprobar que todo funciona.

---

## 2. Buscar imágenes en Docker Hub
**Objetivo:** Practicar el comando `docker search`.  
**Instrucciones:**
- Busca imágenes oficiales de **nginx** y **mysql**.  
- Busca también imágenes del usuario `adbgonzalez`.  
- Filtra solo las oficiales y las que tengan más de 20 estrellas.

---

## 3. Descargar imágenes
**Objetivo:** Usar `docker pull` para obtener imágenes locales.  
**Instrucciones:**
- Descarga las imágenes: `nginx`, `httpd`, `mysql:5.7`.  
- Comprueba que están disponibles con el comando `docker images`.

---

## 4. Crear un contenedor web básico
**Objetivo:** Ejecutar tu primer contenedor web.  
**Instrucciones:**
- Usa la imagen `nginx`.  
- El contenedor debe llamarse `web1`.  
- Ejecútalo en modo interactivo y en segundo plano.  
- Mapea el puerto `8080` del host con el `80` del contenedor.

---

## 5. Parar y eliminar contenedores
**Objetivo:** Controlar la ejecución y limpieza de contenedores.  
**Instrucciones:**
- Detén el contenedor `web1`.  
- Elimínalo del sistema.  
- Comprueba que ya no aparece en la lista.

---

## 6. Ejecutar un contenedor Apache con nombre y puerto
**Objetivo:** Crear un contenedor de Apache accesible desde el host.  
**Instrucciones:**
- Usa la imagen `httpd`.  
- Nombra el contenedor `apache1`.  
- Mapea el puerto `8081` al `80`.

---

## 7. Consultar logs y procesos
**Objetivo:** Inspeccionar la actividad de un contenedor.  
**Instrucciones:**
- Muestra los logs del contenedor `apache1`.  
- Lista los procesos en ejecución dentro del contenedor.

---

## 8. Acceder a la consola de un contenedor
**Objetivo:** Entrar en el sistema interno de un contenedor.  
**Instrucciones:**
- Accede a la shell del contenedor `apache1`.  
- Lista el contenido del directorio `/usr/local/apache2/htdocs`.  
- Sal de la shell.

---

## 9. Crear un contenedor MySQL configurado
**Objetivo:** Probar el uso de variables de entorno.  
**Instrucciones:**
- Usa la imagen `mysql:5.7`.  
- Nombra el contenedor `bd1`.  
- Añade la variable `MYSQL_ROOT_PASSWORD=1234`.

---

## 10. Inspeccionar contenedores e imágenes
**Objetivo:** Consultar detalles técnicos.  
**Instrucciones:**
- Inspecciona el contenedor `apache1`.  
- Inspecciona la imagen `nginx`.

---

## 11. Crear una imagen personalizada a partir de un contenedor
**Objetivo:** Generar una nueva imagen.  
**Instrucciones:**
- A partir del contenedor `apache1`, crea una nueva imagen llamada `apache-personal`.  
- Lista las imágenes para comprobar que se creó.

---

## 12. Eliminar y restaurar una imagen
**Objetivo:** Practicar copia y restauración de imágenes.  
**Instrucciones:**
- Guarda la imagen `apache-personal` en un archivo `apache.tar`.  
- Elimínala.  
- Recupérala con el comando `docker load`.

---

## 13. Crear un contenedor con volumen local
**Objetivo:** Probar montajes de directorios.  
**Instrucciones:**
- Crea el directorio `/web` en el host.  
- Crea dentro un archivo `index.html` con texto.  
- Ejecuta un contenedor `apache-vol` basado en `httpd` montando `/web` en `/usr/local/apache2/htdocs`.  
- Mapea el puerto `8082`.

---

## 14. Crear un volumen nombrado y usarlo
**Objetivo:** Emplear volúmenes gestionados por Docker.  
**Instrucciones:**
- Crea un volumen llamado `datosapp`.  
- Usa ese volumen en un contenedor `web2` basado en `nginx`.

---

## 15. Comprobar información de un volumen
**Objetivo:** Usar el comando `docker volume inspect`.  
**Instrucciones:**
- Inspecciona el volumen `datosapp`.  
- Accede al contenedor `web2` y comprueba el montaje.

---

## 16. Limitar recursos de un contenedor
**Objetivo:** Controlar consumo de memoria.  
**Instrucciones:**
- Crea un contenedor `apache-limit` con `httpd`.  
- Limítalo a 256MB de RAM y desactiva el swap.

---

## 17. Configurar reinicio automático
**Objetivo:** Probar políticas de reinicio.  
**Instrucciones:**
- Crea un contenedor `nginx-auto` que se reinicie automáticamente salvo que lo detengas explícitamente.

---

## 18. Exposición automática de puertos
**Objetivo:** Emplear el parámetro `-P`.  
**Instrucciones:**
- Lanza un contenedor `apache-auto` con `httpd` y el parámetro `-P`.  
- Muestra los puertos publicados.

---

## 19. Etiquetar una imagen personalizada
**Objetivo:** Aprender el uso de `docker tag`.  
**Instrucciones:**
- Etiqueta la imagen `apache-personal` con el nombre `usuario/apache-lab:v1`.  
- Lista las imágenes disponibles.

---

## 20. Subir una imagen a Docker Hub
**Objetivo:** Publicar la imagen creada.  
**Instrucciones:**
- Inicia sesión con tu usuario de Docker Hub.  
- Sube la imagen `usuario/apache-lab:v1`.  
- Cierra sesión.
