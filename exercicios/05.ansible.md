# Tarefa: Introdución a Ansible
Segue os pasos para configurar o entorno descrito no documento [text](../09.ansible-introducion.md). Unha vez teñas ansible configurado e todo o entorno operativo fai un playbook que realice as seguintes tarefas:
- Instalar o paquete `git`.
- Crear un fichiro chamado `/tmp/tarefa2` con permisos `777`.
- Engadir ao final dese ficheiro a cadea `tarefa2!`.
- Todas estas accións deben realizarse sobre a máquina `srv1`.
