# Boletín de Docker Compose

## 1. Servidor web estático con Nginx
**Objetivo:** Servir una página HTML estática mediante Docker Compose.

**Tareas a realizar:**
1. Crea un directorio llamado `web-compose` para el ejercicio.
2. Dentro del directorio, crea un archivo `index.html` con el siguiente contenido mínimo:
   - Un título principal con el texto: **¡Bienvenido a Docker Compose!**
   - Un párrafo adicional explicando que es una página servida por Nginx en un contenedor.
3. Crea un archivo `docker-compose.yml` que:
   - Defina un servicio llamado `web` basado en la imagen `nginx:alpine`.
   - Mapee el puerto `8080` del host con el puerto `80` del contenedor (es decir, `8080:80`).
   - Monte el archivo `index.html` local en la ruta del contenedor `/usr/share/nginx/html/index.html`.
   - Opcional: establece un `container_name` identificable (por ejemplo, `web_nginx`).
4. Arranca el proyecto en **modo detached**.
5. Prueba en el navegador en `http://localhost:8080` y comprueba que se ve la página.
6. Cierra y limpia los recursos creados al finalizar.

**Entrega esperada:**
- Estructura de directorios del ejercicio.
- El archivo `docker-compose.yml`.
- El archivo `index.html`.

## 2. Aplicación Flask con base de datos MySQL
**Objetivo:** Levantar una aplicación web Python (Flask) que se conecte a una base de datos MySQL, todo orquestado con Docker Compose.

**Tareas a realizar:**
1. Crea un directorio llamado `flask-mysql`.
2. Dentro, crea un subdirectorio `app` para la aplicación Flask.
3. En la carpeta `app`, crea estos archivos:
   - `app.py`: Una ruta raíz `/` que devuelva un texto leído a través de una consulta a la BD. Debe conectarse a MySQL usando las variables de entorno (contraseña, host, etc.).
   - `requirements.txt`: Incluye al menos `Flask==3.0.0` y `mysql-connector-python==9.1.0`.
   - `Dockerfile`: Usa `python:3.12-slim`, instala dependencias de `requirements.txt` y ejecuta `python app.py`.
4. En el nivel superior, crea `docker-compose.yml` con:
   - Servicio `web` que **se construye** desde `./app`, expone `5000:5000` y depende del servicio `db`.
   - Servicio `db` basado en `mysql:8.0` que establezca:
     - `MYSQL_ROOT_PASSWORD` (por ejemplo, `1234`)
     - `MYSQL_DATABASE` (por ejemplo, `demo`)
     - Un volumen persistente montado en `/var/lib/mysql`.
5. Arranca en **modo detached** y comprueba en `http://localhost:5000` que la app responde con un mensaje (por ejemplo: *¡Docker Compose con Flask y MySQL funcionando!*).
6. Cierra y **limpia también el volumen** al finalizar (para dejar todo como estaba).

**Entrega esperada:**
- Estructura de directorios completa del ejercicio.
- Contenido de `docker-compose.yml`.
- Contenido de `app/app.py`, `app/requirements.txt` y `app/Dockerfile`.
