# Boletín de ejercicios de Dockerfile (enunciados)

## 1. Comando básico de bash dentro de un contenedor
**Objetivo:** crear una imagen mínima que ejecute un comando de shell al iniciar.  
**Instrucciones:**
1) Usa la imagen base `alpine:3.20`.  
2) Haz que el contenedor ejecute un comando que liste el contenido del directorio raíz y, a continuación, muestre los procesos en ejecución.  
3) Construye la imagen con el nombre `bash-mini:ls-ps` y ejecútala.

---

## 2. Servidor web con Nginx
**Objetivo:** servir un HTML estático.  
**Instrucciones:**
1) Usa la imagen base `nginx:alpine`.  
2) Crea un `index.html` con el texto “Bienvenido a Nginx en Docker” y cópialo a `/usr/share/nginx/html/` en el contenedor.  
3) Expón el puerto `80` en el Dockerfile.  
4) Construye la imagen `web:nginx` y lánzala mapeando el puerto `8080:80` del host.

---

## 3. Aplicación Flask con requirements.txt
**Objetivo:** levantar un pequeño servidor Flask.  
**Instrucciones:**
1) Crea `requirements.txt` con una dependencia: `Flask==3.0.0`.  
2) Crea `app.py` con un endpoint raíz que devuelva “Hola desde Flask y Docker!”.  
3) En el Dockerfile: usa `python:3.12-slim`, copia e instala `requirements.txt`, copia el código, expón `5000` y define `CMD` para ejecutar la app.  
4) Construye la imagen `flask:web` y ejecútala mapeando `5000:5000`.

---

## 4. Versión avanzada con script de inicio, usuario no root y HEALTHCHECK
**Objetivo:** integrar buenas prácticas.  
**Instrucciones:**
1) Base: `python:3.12-slim`.  
2) Crea `start.sh` que muestre un mensaje y ejecute el comando recibido.  
3) Añade un usuario `appuser` y ejecuta la app con él.  
4) Instala dependencias desde `requirements.txt` (puedes reutilizar el del ejercicio 3).  
5) Añade un `HEALTHCHECK` que realice una petición HTTP al puerto de la app cada 30 segundos.  
6) Construye la imagen `flask:secure` y ejecútala en segundo plano mapeando `8000:8000`.
