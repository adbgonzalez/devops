# Guía: Conexión SSH a unha VM NAT e traballo remoto con VS Code

## Contexto

Tes unha máquina virtual (VM) en VirtualBox cun adaptador en modo NAT.  
A VM expón o porto 22 (SSH) ao host a través dun port forwarding, por exemplo o porto 2222.  
O obxectivo é:

1. Acceder por SSH sen contrasinal.  
2. Usar VS Code para abrir carpetas da VM como se fosen locais.

---

## 1. Xerar un par de claves SSH no host

No host (Windows, Linux ou macOS) abre un terminal e executa:

```bash
ssh-keygen -t ed25519 -C "tua_identidade"
```

- Cando pida localización, acepta o valor por defecto:  
  `~/.ssh/id_ed25519`
- Cando pida frase de paso, podes deixala baleira (para non tela que escribir cada vez).

Isto crea dous ficheiros:
- Privada: `~/.ssh/id_ed25519`
- Pública: `~/.ssh/id_ed25519.pub`

---

## 2. Confirmar o port forwarding en VirtualBox

Abre VirtualBox → Configuración da VM → Rede → Avanzado → Reenvío de Portos

Deberías ter algo así:

| Nome | Protocolo | IP anfitrión | Porto anfitrión | IP convidado | Porto convidado |
|------|------------|---------------|----------------|---------------|----------------|
| SSH  | TCP        | —             | 3022           | —             | 22             |

Isto significa que cando te conectas ao porto 3022 do host, VirtualBox reenvía o tráfico ao porto 22 da VM (SSH).

---

## 3. Copiar a clave pública ao usuario da VM

Primeiro comproba que podes entrar con contrasinal:

```bash
ssh -p 2222 usuario@localhost
```

Unha vez dentro, crea o directorio SSH:

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
```

Agora, desde o host, copia a clave pública:

```bash
scp -P 2222 ~/.ssh/id_ed25519.pub usuario@localhost:~/.ssh/authorized_keys
```

Se xa existe o ficheiro `authorized_keys`, podes engadir a clave así:

**Windows (PowerShell):**
```bash
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh -p 2222 usuario@localhost "cat >> ~/.ssh/authorized_keys"
```

**Linux/macOS:**
```bash
cat ~/.ssh/id_ed25519.pub | ssh -p 2222 usuario@localhost "cat >> ~/.ssh/authorized_keys"
```

Logo na VM:

```bash
chmod 600 ~/.ssh/authorized_keys
```

Proba o acceso sen contrasinal:

```bash
ssh -p 2222 usuario@localhost
```

---

## 4. Simplificar o acceso con `~/.ssh/config`

No host, edita ou crea o ficheiro `~/.ssh/config`:

```bash
Host controlnode
  HostName localhost
  Port 2222
  User usuario
  IdentityFile ~/.ssh/id_ed25519
```

Agora podes conectarte simplemente con:

```bash
ssh controlnode
```

---

## 5. Conectarte desde VS Code

1. Instala en VS Code a extensión **Remote - SSH** (de Microsoft).  
2. Preme `F1` → escribe `Remote-SSH: Connect to Host…`.  
3. Escolle o alias configurado en `~/.ssh/config` (por exemplo, `controlnode`).  
4. VS Code abrirá unha sesión SSH e instalará o servidor remoto na VM automaticamente.

---

## 6. Abrir un directorio remoto na VM

Unha vez conectado, verás abaixo `SSH: controlnode`.

Podes abrir carpetas da VM:  
`File → Open Folder…` e escolle algo como `/home/ansible/proxecto`.

Tamén podes usar o terminal integrado de VS Code, que agora será o terminal da VM.

---

## 7. Verificar conexión e permisos

Se tes problemas, executa:

```bash
ssh controlnode -v
```

Asegúrate de que os permisos son correctos:

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

Se usas Windows, comproba que PowerShell permite usar `ssh-keygen`. Se non, podes empregar Git Bash.

---

## Resumo

| Paso | Acción | Comando principal |
|------|---------|------------------|
| 1 | Xerar clave | `ssh-keygen -t ed25519` |
| 2 | Ver port forwarding | Porto host 2222 → convidado 22 |
| 3 | Copiar clave pública | `scp -P 2222 ~/.ssh/id_ed25519.pub ...` |
| 4 | Simplificar acceso | Editar `~/.ssh/config` |
| 5 | Conexión desde VS Code | Remote-SSH |
| 6 | Traballar nun directorio remoto | `File → Open Folder…` |
| 7 | Verificar permisos | `chmod 700 ~/.ssh` / `chmod 600 authorized_keys` |
